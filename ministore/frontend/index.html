Application Architecture

How MiniStore communicates across container boundaries

01. Frontend Tier

Nginx & Static Assets

Lightweight Nginx Alpine container serving HTML, CSS, and Vanilla JS on port 80. Proxies all /api/* traffic to the backend, avoiding browser CORS complications.

02. Backend Tier

Python Flask REST API

Containerized Python 3.11 service exposing /api/health, /api/products, and transactional /api/orders on port 5000.

03. Data Tier

PostgreSQL Database

Relational storage for products, orders, and order line items. Configured via standard database credentials and environment variables.
